# CUBRID 문서 용어집

`cubrid-doc` 4단계가 이 파일과 대조한다. 왼쪽이 대상, 가운데가 쓸 표기, 오른쪽이 그 표기를 정한 근거다.

## 근거 우선순위

아래 순서로 찾고, 먼저 확정되는 것을 쓴다.

| 순위 | 근거 | 무엇을 정하나 | 어디서 확인하나 |
|---|---|---|---|
| 1 | 기존 CUBRID 한국어 표기 | 표기 전체 | `~/github/develop/msg/ko_KR.utf8/*.msg` 4,048줄. 벤더가 쓴 한국어다. 출현 횟수와 파일을 함께 적고, 표기가 갈리면 다수 표기와 비율을 적는다. 한국어 매뉴얼 저장소는 로컬에 없다 |
| 2 | 국립국어원 외래어 표기법 | **한글 철자만** | https://kornorms.korean.go.kr |
| 3 | TTA 정보통신용어사전 | 정보통신 표준 용어 | https://terms.tta.or.kr -- 검색이 POST/JavaScript 다. **GET 조회로 확인할 수 없으므로 스킬은 자동 조회하지 않는다.** 시도해서 실패를 반복하지 않는다. 대상은 `references/tta-pending.md` 에 모은다 |
| 4 | 팀 결정 | 위 셋으로 갈리지 않을 때 | 날짜를 함께 적는다 |

`영문 유지` 인지 `한글 표기` 인지는 **팀 결정**이다. 한글로 쓸 경우의 철자는 **국립국어원 외래어 표기법**이 정한다.

| task thread | 태스크 스레드 | `스레드` 는 기존 CUBRID 한국어 표기 11회 (`utils.msg`, `cubrid.msg`). `태스크` 는 국립국어원 외래어 표기법(`태스크포스` 용례) |

| descriptor | 디스크립터 | 기존 CUBRID 한국어 표기 1회 (`cubrid.msg`). 백틱 안 식별자(`add_descriptor`)는 원문 유지 |

| run | 런 | 팀 결정 2026-09-01. 측정을 한 번 실행한 단위(`2런`). 메시지 카탈로그 0회 -- `이런` 의 부분 일치만 걸린다. `tta-pending.md` |
| 반복 측정의 변동 범위 | 폭 | 팀 결정 2026-09-01. 같은 조건을 반복 측정했을 때의 최대와 최소 간격. 메시지 카탈로그 0회 |
| handoff | 핸드오프 | 팀 결정 2026-09-01. `HANDOFF_CLIENT` 가 지나는 경로를 가리킬 때 쓴다. 워커 사이에서 연결을 옮기는 동작 자체를 서술할 때는 `이관` 이다. 메시지 카탈로그 0회 -- `tta-pending.md` |
| race window | 경합 구간 | 팀 결정 2026-09-01. `창` 을 쓰지 않는다 -- 단독으로는 뜻이 드러나지 않는다. `구간` 은 기존 CUBRID 한국어 표기 1회(`cubrid.msg`, `인덱스 빌드 구간`) |
| test axis | 테스트 관점 | 팀 결정 2026-09-01. `축` 을 쓰지 않는다. 메시지 카탈로그 0회 -- `tta-pending.md` |
| 메시지나 사건의 분류 | 종류 | 팀 결정 2026-09-01. `갈래` 를 쓰지 않는다 |
| 부하가 도착하는 방식의 묶음 | 방식 | 팀 결정 2026-09-01. `가족` 을 쓰지 않는다 -- 정의 없이는 뜻이 드러나지 않는다 |
| coordinator | coordinator | 팀 결정 2026-09-02. 영문 유지. `coordinator` 는 실제 클래스 이름이다 |
| scaler | scaler | 팀 결정 2026-09-02. 영문 유지. 코드에 이 조정 코드를 묶는 이름이 없어 분석이 붙인 이름이다 |
| drain | drain | 팀 결정 2026-09-02. 영문 유지. 축소되는 워커의 연결을 남은 워커에게 넘기는 과정. 상태 이름 `DRAINING` 과 짝을 맞춘다 |
| scaling window | `history` | 팀 결정 2026-09-02. 한 사이클이 비교할 워커 수의 목록. `창` 을 쓰지 않는다 -- `race window` 항과 같은 이유다. 코드의 상자 이름을 그대로 쓴다 |

## 문서 안에서 정의해 쓰는 용어

아래는 이 용어집이 표기를 정하되, 뜻은 각 문서의 용어 표가 정한다.

| 용어 | 표기 | 근거 | 뜻을 정하는 자리 |
|---|---|---|---|
| 요청 | 요청 | 기존 CUBRID 한국어 표기 10회 (`utils.msg`, `cubrid.msg`) | 클라이언트가 보내는 질의나 명령. 큐에 담기는 내부 요청은 `메시지` 라 적어 가른다 |
| 메시지 | 메시지 | 기존 CUBRID 한국어 표기 34회 (`csql.msg`, `utils.msg`, `cubrid.msg`) | 워커 큐에 담기는 내부 요청. 코드 타입 이름이 `message` 다 |

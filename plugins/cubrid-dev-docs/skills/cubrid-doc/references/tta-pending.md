# TTA 확인 대기

TTA 정보통신용어사전(https://terms.tta.or.kr) 확인이 필요한 용어를 모은다.

`terms.tta.or.kr` 은 검색을 POST/JavaScript 로 처리하므로 GET 조회로 확인할 수 없다. **스킬은 TTA 를 자동 조회하지 않는다.** 4.5단계는 `TTA 미확인` 으로 표시하고 다른 근거로 결정을 진행한다. TTA 때문에 문서 작업을 멈추지 않는다.

사용자가 `TTA 확인했어` 라고 결과를 주면 `glossary.md` 의 근거 칸을 갱신하고 이 파일에서 해당 행을 지운다.

| 용어 | 잠정 표기 | 잠정 근거 | 확인 필요 이유 |
|---|---|---|---|
| worker | 워커 | 팀 결정 2026-09-01 | 메시지 카탈로그 0회. 벤더 한국어 표기가 없다 |
| queue | 큐 | 팀 결정 2026-09-01 | 메시지 카탈로그 0회 |
| timer | 타이머 | 팀 결정 2026-09-01 | 메시지 카탈로그 0회 |
| context | 컨텍스트 | 팀 결정 2026-09-01 | 메시지 카탈로그 0회. 외래어 표기법 강세 기준으로는 `콘텍스트` 가 될 여지가 있다 |
| hot path | 핫패스 | 팀 결정 2026-09-01 | 메시지 카탈로그 0회. 음차와 번역(`빈발 경로`)이 갈릴 수 있다 |
| durability | durability | 팀 결정 2026-09-01 | 영문 유지를 정했으나 TTA 표준 용어가 있으면 대조가 필요하다 |
| barrier | barrier | 팀 결정 2026-09-01 | 같은 이유 |
| run | 런 | 팀 결정 2026-09-01 | 메시지 카탈로그 0회. `수행` 이나 `회차` 로 갈릴 수 있다 |
| handoff | 핸드오프 | 팀 결정 2026-09-01 | 메시지 카탈로그 0회. 음차와 번역(`이관`)이 갈릴 수 있다 |
| test axis | 테스트 관점 | 팀 결정 2026-09-01 | 메시지 카탈로그 0회. TTA 에 대응 표준 용어가 있는지 확인이 필요하다 |
